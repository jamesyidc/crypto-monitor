# 加密货币实时监控系统

## 项目概述

这是一个功能强大的加密货币实时监控系统，用于追踪和分析 29 种主流数字货币的价格变化，提供全面的市场趋势分析和风险提示。

### 核心特性

- **29种主流币种监控**: BTC、ETH、XRP、BNB、SOL、LTC、DOGE、SUI、TRX、TON、ETC、BCH、HBAR、XLM、FIL、ADA、LINK、CRO、DOT、OKB、AAVE、UNI、NEAR、APT、CFX、CRV、STX、LDO、TAO
- **10分钟自动数据采集**: 定时从 CoinGecko API 获取最新价格数据
- **美元计价**: 所有价格均以美元为计价单位
- **智能分析引擎**: 自动计算涨跌幅、急涨急跌、极端行情
- **市场趋势判断**: 识别单边主升、震荡偏多、无序震荡、震荡偏空、单边主跌等五种市场状态
- **创新高/新低追踪**: 实时记录历史最高价和最低价，并统计创新高/新低次数
- **币种优先级系统**: 根据最高占比和最低占比自动分配1-6等级
- **风险提示**: 当所有币种全部下跌时自动触发风险警告

## 功能详解

### 1. 实时价格监控

每10分钟采集一次数据，显示：
- 当前价格（美元）
- 10分钟涨跌幅
- 24小时涨跌幅
- 24小时涨跌幅排名

**颜色标识**:
- 🟢 绿色：上涨
- 🔴 红色：下跌

### 2. 涨跌分析

**涨跌统计**:
- 绿色占比：上涨币种数量 / 总币种数量
- 红色占比：下跌币种数量 / 总币种数量

**急涨急跌**（每轮统计）:
- 急涨：单轮涨幅 ≥ 1%
- 急跌：单轮跌幅 ≤ -1%
- 累计今日急涨/急跌总次数

**极端行情**（每轮统计）:
- 极涨：单轮涨幅 ≥ 4%
- 极跌：单轮跌幅 ≤ -3%

### 3. 市场趋势分析

系统根据以下规则判断市场趋势：

**五种市场状态**:

1. **单边主升** ⭐⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 3
   - 特征：强烈上涨趋势

2. **震荡偏多** ⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 1
   - 特征：上涨趋势，但有波动

3. **无序震荡**
   - 条件：急涨 < 10 且 急跌 < 10
   - 特征：市场方向不明确

4. **震荡偏空** ☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 1
   - 特征：下跌趋势，但有反弹

5. **单边主跌** ☆☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 3
   - 特征：强烈下跌趋势

**趋势强度星级**:
- 比值 = |急涨 - 急跌| / min(急涨, 急跌)
- 1-2：⭐ 一颗星
- 2-3：⭐⭐ 两颗星
- ≥3：⭐⭐⭐ 三颗星

**星星类型**:
- ⭐ 实心黑星：急涨
- ☆ 空心黑星：急跌

### 4. 创新高/创新低

**比价系统**:
- 系统储存每个币种的历史最高价和最低价
- 每轮结束后，将当前价格与历史极值比较
- 如果价格 > 历史最高价 → 创新高，更新记录并计次
- 如果价格 < 历史最低价 → 创新低，更新记录并计次

**占比计算**:
- 最高占比 = (当前价格 / 历史最高价) × 100%
- 最低占比 = (当前价格 / 历史最低价) × 100%

### 5. 币种优先级等级

根据最高占比和最低占比自动分配等级：

| 等级 | 条件 | 说明 |
|------|------|------|
| 🥇 等级1 | 最低占比 ≥ 120% 且 最高占比 ≥ 90% | 价格接近历史高位且远离低位 |
| 🥈 等级2 | 最低占比 ≥ 120% 且 最高占比 ≥ 80% | 价格较高且远离低位 |
| 🥉 等级3 | 最低占比 ≥ 110% 且 最高占比 ≥ 90% | 价格接近历史高位 |
| 4️⃣ 等级4 | 最低占比 ≥ 110% 且 最高占比 ≥ 80% | 价格较高 |
| 5️⃣ 等级5 | 最低占比 < 110% 且 最高占比 ≥ 90% | 价格接近历史高位但靠近低位 |
| 6️⃣ 等级6 | 其他情况 | 价格处于中低位 |

### 6. 风险提示

当绿色占比 = 0%（所有币种全部下跌）时，系统会：
- 风险计次 +1
- 显示 "⚠️ 注意风险" 警告

## 技术架构

- **框架**: Hono (轻量级 Web 框架)
- **运行时**: Cloudflare Workers / Pages
- **数据库**: Cloudflare D1 (SQLite)
- **前端**: HTML + TailwindCSS + Vanilla JavaScript
- **数据源**: CoinGecko API
- **部署**: Cloudflare Pages

## 数据库结构

### 核心表

1. **coins** - 币种配置
2. **price_records** - 价格记录（每10分钟）
3. **price_extremes** - 历史最高/最低价
4. **round_stats** - 轮次统计
5. **coin_round_details** - 单币轮次详情
6. **daily_stats** - 日统计
7. **extreme_records** - 创新高/新低记录
8. **coin_priority** - 币种优先级

## API 端点

### GET /api/dashboard
获取仪表板数据（最新轮次、币种详情、今日统计、极值数据、优先级）

### POST /api/analyze
执行一轮数据采集和分析

### GET /api/coins
获取所有币种列表

### GET /api/rounds?limit=50
获取历史轮次统计

## 本地开发

### 前置要求
- Node.js 18+
- npm

### 安装依赖
```bash
npm install
```

### 初始化数据库

## 部署到 Cloudflare Pages

### 1. 创建 D1 数据库
```bash
npx wrangler d1 create webapp-production
```

### 2. 更新 wrangler.jsonc
将返回的 database_id 填入配置文件：
```jsonc
{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "webapp-production",
      "database_id": "你的数据库ID"
    }
  ]
}
```

### 3. 应用生产数据库迁移
```bash
npm run db:migrate:prod
```

### 4. 部署项目
```bash
npm run deploy:prod
```

## 数据说明

### 数据来源
- 价格数据来自 **CoinGecko Free API**
- 更新频率：每10分钟
- 计价单位：美元 (USD)

### 数据限制
- CoinGecko 免费版 API 有请求频率限制
- 建议不要过于频繁地手动触发分析
- 自动10分钟更新已经是合理的频率
