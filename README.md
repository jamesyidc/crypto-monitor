# 加密货币实时监控系统

## 项目概述

这是一个功能强大的加密货币实时监控系统，用于追踪和分析 29 种主流数字货币的价格变化，提供全面的市场趋势分析和风险提示。

### 核心特性

- **29种主流币种监控**: BTC、ETH、XRP、BNB、SOL、LTC、DOGE、SUI、TRX、TON、ETC、BCH、HBAR、XLM、FIL、ADA、LINK、CRO、DOT、OKB、AAVE、UNI、NEAR、APT、CFX、CRV、STX、LDO、TAO
- **10分钟自动数据采集**: 定时从 CoinGecko API 获取最新价格数据
- **美元计价**: 所有价格均以美元为计价单位
- **智能分析引擎**: 自动计算涨跌幅、急涨急跌、极端行情
- **市场趋势判断**: 识别单边主升、震荡偏多、无序震荡、震荡偏空、单边主跌等五种市场状态
- **创新高/新低追踪**: 实时记录历史最高价和最低价，并统计创新高/新低次数
- **币种优先级系统**: 根据最高占比和最低占比自动分配1-6等级
- **风险提示**: 当所有币种全部下跌时自动触发风险警告
- **🆕 K线数据查询**: 集成 OKX API，支持多时间周期K线数据查询和历史数据存储
- **📊 K线图表展示**: 可视化K线数据，支持5分钟、15分钟、1小时、4小时、1天等多个时间周期

## 功能详解

### 1. 实时价格监控

每10分钟采集一次数据，显示：
- 当前价格（美元）
- 10分钟涨跌幅
- 24小时涨跌幅
- 24小时涨跌幅排名

**颜色标识**:
- 🟢 绿色：上涨
- 🔴 红色：下跌

### 2. 涨跌分析

**涨跌统计**:
- 绿色占比：上涨币种数量 / 总币种数量
- 红色占比：下跌币种数量 / 总币种数量

**急涨急跌**（每轮统计）:
- 急涨：单轮涨幅 ≥ 1%
- 急跌：单轮跌幅 ≤ -1%
- 累计今日急涨/急跌总次数

**极端行情**（每轮统计）:
- 极涨：单轮涨幅 ≥ 4%
- 极跌：单轮跌幅 ≤ -3%

**🆕 极端行情累计次数**（连续触发计次）:
- **+4% 列**：当涨幅 ≥ +4% 时累加计数，否则重置为 0
- **-3% 列**：当跌幅 ≤ -3% 时累加计数，否则重置为 0
- 说明：这两列专门用于追踪连续极端行情的持续时间
- 计次规则：
  - 满足条件时：计数 +1
  - 不满足条件时：计数重置为 0（不保留历史）

### 3. 市场趋势分析

系统根据以下规则判断市场趋势：

**五种市场状态**:

1. **单边主升** ⭐⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 3
   - 特征：强烈上涨趋势

2. **震荡偏多** ⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 1
   - 特征：上涨趋势，但有波动

3. **无序震荡**
   - 条件：急涨 < 10 且 急跌 < 10
   - 特征：市场方向不明确

4. **震荡偏空** ☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 1
   - 特征：下跌趋势，但有反弹

5. **单边主跌** ☆☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 3
   - 特征：强烈下跌趋势

**趋势强度星级**:
- 比值 = |急涨 - 急跌| / min(急涨, 急跌)
- 1-2：⭐ 一颗星
- 2-3：⭐⭐ 两颗星
- ≥3：⭐⭐⭐ 三颗星

**星星类型**:
- ⭐ 实心黑星：急涨
- ☆ 空心黑星：急跌

### 4. 🆕 创新高/创新低 - 动态计次系统

**比价系统**:
- 系统储存每个币种的历史最高价和最低价
- 每轮结束后，将当前价格与历史极值比较

**🆕 动态计次规则**:
1. **创新高时** (`current_price > all_time_high`):
   - 更新 `all_time_high` 为当前价格
   - 重置 `high_count = 0`
   - 记录新高事件

2. **未创新高时**:
   - 保持 `all_time_high` 不变
   - `high_count` 加 1（计次累积）

3. **创新低时** (`current_price < all_time_low`):
   - 更新 `all_time_low` 为当前价格
   - 重置 `low_count = 0`
   - 记录新低事件

4. **未创新低时**:
   - 保持 `all_time_low` 不变
   - `low_count` 加 1（计次累积）

**占比计算**:
- **最高占比** = (当前价格 / 历史最高价) × 100% (≤100%)
- **最低占比** = (当前价格 / 历史最低价) × 100% (≥100%)

**计次意义**:
- `high_count`: 表示自上次创新高以来已经过了多少轮分析
- `low_count`: 表示自上次创新低以来已经过了多少轮分析
- 计次越大，说明距离上次极值时间越久

### 5. 币种优先级等级

根据最高占比和最低占比自动分配等级：

| 等级 | 条件 | 说明 |
|------|------|------|
| 🥇 等级1 | 最低占比 ≥ 120% 且 最高占比 ≥ 90% | 价格接近历史高位且远离低位 |
| 🥈 等级2 | 最低占比 ≥ 120% 且 最高占比 ≥ 80% | 价格较高且远离低位 |
| 🥉 等级3 | 最低占比 ≥ 110% 且 最高占比 ≥ 90% | 价格接近历史高位 |
| 4️⃣ 等级4 | 最低占比 ≥ 110% 且 最高占比 ≥ 80% | 价格较高 |
| 5️⃣ 等级5 | 最低占比 < 110% 且 最高占比 ≥ 90% | 价格接近历史高位但靠近低位 |
| 6️⃣ 等级6 | 其他情况 | 价格处于中低位 |

### 6. 风险提示

当绿色占比 = 0%（所有币种全部下跌）时，系统会：
- 风险计次 +1
- 显示 "⚠️ 注意风险" 警告

### 7. 🆕 K线数据查询

**数据来源**: OKX 交易所 API

**支持的时间周期**:
- 5分钟 (5m)
- 15分钟 (15m)
- 1小时 (1H)
- 4小时 (4H)
- 1天 (1D)

**功能特性**:
- ✅ 实时同步 K线数据（最多300根K线）
- ✅ 历史数据存储和查询
- ✅ K线统计信息（涨跌幅、最高最低价、成交量）
- ✅ 可视化图表展示
- ✅ 多时间周期对比
- ✅ 单个币种详细查询

**OKX 配置参数**:
- V1: 第一阈值参数
- V2: 第二阈值参数

每个币种都有独立的 OKX 交易对配置（如 BTC-USDT-SWAP）

4. **round_stats** - 轮次统计
5. **coin_round_details** - 单币轮次详情

7. **extreme_records** - 创新高/新低记录
8. **coin_priority** - 币种优先级
9. **🆕 kline_data** - K线历史数据
10. **🆕 okx_config** - OKX 币种配置（V1/V2参数）

## API 端点

### 现货价格监控 API

#### GET /api/dashboard
获取仪表板数据（最新轮次、币种详情、今日统计、极值数据、优先级）

#### POST /api/analyze
执行一轮数据采集和分析

#### GET /api/coins
获取所有币种列表

#### GET /api/rounds?limit=50
获取历史轮次统计

#### 🆕 GET /api/compare
获取比价数据（动态计次系统）
- 返回所有币种的极值数据
- 包含 `high_count` 和 `low_count` 实时计次
- 自动计算最高占比和最低占比
- 用于比价比对页面的数据源

### 🆕 K线数据 API

#### POST /api/kline/sync?timeframe=5m&limit=300
同步所有币种的 K线数据
- `timeframe`: 时间周期（5m/15m/1H/4H/1D）
- `limit`: 获取的K线数量（默认300）

#### GET /api/kline/:symbol?timeframe=5m&limit=100
获取单个币种的 K线数据
- `symbol`: 币种符号（如 BTC）
- `timeframe`: 时间周期
- `limit`: 返回的K线数量

#### GET /api/kline/:symbol/stats?timeframe=5m&limit=100
获取 K线统计信息（涨跌幅、最高最低价、成交量等）

#### GET /api/kline/:symbol/multi
获取单个币种的多时间周期数据（5m/15m/1H/4H/1D）

#### GET /api/okx/config
获取所有币种的 OKX 配置

#### GET /api/okx/config/:symbol
获取单个币种的 OKX 配置

### 🆕 技术指标 API

#### GET /api/kline/:symbol/indicators?timeframe=5m&limit=300
获取带技术指标的 K线数据（SAR、RSI、BOLL、通道状态）
- 自动获取额外50根历史数据确保指标完整性
- 返回用户请求的数量，所有K线都有完整指标值

#### POST /api/kline/indicators/batch
批量获取多个币种的技术指标
```json
{
  "symbols": ["BTC", "ETH", "XRP"],
  "timeframe": "5m",
  "limit": 300
}
```

#### POST /api/kline/sync48h/all
同步所有币种的48小时历史数据（576根5分钟K线）

#### POST /api/kline/:symbol/sync48h
同步单个币种的48小时历史数据

### 🆕 买卖点信号 API

#### GET /api/signal/:symbol?timeframe=5m&limit=100&telegram=true
获取单个币种的买卖点信号（自动发送Telegram预警）
- 返回所有符合条件的买卖点信号
- 包含信号强度评分（0-100）
- 详细的技术指标数据
- **🆕 自动发送预警到Telegram**（默认开启，设置`telegram=false`关闭）
- 返回Telegram发送状态（成功/失败数量）

#### GET /api/signal/all?timeframe=5m&limit=100
获取所有币种的买卖点信号汇总
- 汇总统计信息（总信号数、做多/做空数量）
- 顶级信号列表（强度≥60）
- 所有有信号的币种详情

#### GET /api/telegram/test
测试Telegram连接状态
- 验证Bot Token和Chat ID是否有效
- 发送测试消息到配置的频道
- 返回连接诊断信息

## 🆕 Telegram预警通知

### 功能概述

系统现已集成Telegram预警通知功能，当K线数据满足特定条件时，会自动发送详细的预警消息到您的Telegram频道。

### 触发条件（OR逻辑）

预警采用**OR逻辑**，只要满足以下任一条件即触发：

1. **成交量触发**:
   - 成交量 ≥ V1（平均成交量 × 1.5）
   - 成交量 ≥ V2（平均成交量 × 1.0）

2. **价格变化触发**:
   - 涨幅 ≥ 1%
   - 跌幅 ≤ -1%

3. **震荡触发**:
   - 波动率 ≥ 1%（计算公式：(最高价 - 最低价) / 最低价 × 100%）

## 数据说明

### 数据来源

- **现货价格数据**: 多数据源备份机制 🛡️
  - 主数据源：CoinGecko Free API
  - 备份数据源1：Binance API
  - 备份数据源2：CryptoCompare API
  - 更新频率：每10分钟（自动）
  - 计价单位：美元 (USD)
  - **故障转移**：当主数据源失败时自动切换到备份源，确保数据持续更新
  
- **🆕 K线数据**: OKX Exchange API
  - 更新方式：**每5分钟自动同步** ⚡
  - 同步数量：100根K线（约8小时数据）
  - 时间周期：5m（其他周期可手动查询）
  - 数据存储：本地D1数据库

### 数据限制
- CoinGecko 免费版 API 有请求频率限制（已添加备份数据源）
- Binance API 在某些地区可能受限（451错误）
- CryptoCompare API 免费且稳定，无需API Key
- OKX API 免费且无需注册
- 建议不要过于频繁地手动触发数据同步
- K线数据会存储在本地数据库中，可离线查询历史数据

### 🛡️ 数据可靠性保障
系统采用**三层备份机制**确保数据持续更新：
1. **第一层**：CoinGecko API（主数据源，数据最全面）
2. **第二层**：Binance API（第一备份，速度快）
3. **第三层**：CryptoCompare API（最终备份，稳定性高）

当主数据源出现 429 限流或其他错误时，系统会自动尝试备份数据源，确保10分钟自动刷新不间断。

### 🎯 买卖点信号分析（最新功能）

**功能入口**: 首页点击"买卖点信号"按钮或访问 `/signal.html`

**见顶信号（做空）识别规则**:
1. 震荡幅度 > 1%
2. 长上影线（上影线 > 实体的2倍）
3. 量能衰减（当前成交量 < 前一根的30%）
4. SAR加速上升（sarChangePercent > 0 且 > 5%）
5. 价格转负（开始回落）
6. RSI超买（RSI > 70）
7. 成交量触发（V1/V2/涨跌幅/震荡）

**见底信号（做多）识别规则**:
1. 震荡幅度 > 1%
2. 长下影线（下影线 > 实体的2倍）
3. 量能衰减（当前成交量 < 前一根的30%）
4. SAR加速下降（sarChangePercent < 0 且 > 5%）
5. 价格转正（开始反弹）
6. RSI超卖（RSI < 30）
7. 成交量触发（V1/V2/涨跌幅/震荡）

**信号强度评分**:
- 高强度（≥75分）：重点关注
- 中等强度（60-74分）：值得关注
- 低强度（<60分）：参考信号

**观察期**:
- 做空信号：保留10根K线观察
- 做多信号：保留20根K线观察

详细说明请参阅 [买卖点识别规则](./SIGNAL_RULES.md)
