# 加密货币实时监控系统

## 项目概述

这是一个功能强大的加密货币实时监控系统，用于追踪和分析 29 种主流数字货币的价格变化，提供全面的市场趋势分析和风险提示。

### 核心特性

- **29种主流币种监控**: BTC、ETH、XRP、BNB、SOL、LTC、DOGE、SUI、TRX、TON、ETC、BCH、HBAR、XLM、FIL、ADA、LINK、CRO、DOT、OKB、AAVE、UNI、NEAR、APT、CFX、CRV、STX、LDO、TAO
- **10分钟自动数据采集**: 定时从 CoinGecko API 获取最新价格数据
- **美元计价**: 所有价格均以美元为计价单位
- **智能分析引擎**: 自动计算涨跌幅、急涨急跌、极端行情
- **市场趋势判断**: 识别单边主升、震荡偏多、无序震荡、震荡偏空、单边主跌等五种市场状态
- **创新高/新低追踪**: 实时记录历史最高价和最低价，并统计创新高/新低次数
- **币种优先级系统**: 根据最高占比和最低占比自动分配1-6等级
- **风险提示**: 当所有币种全部下跌时自动触发风险警告
- **🆕 K线数据查询**: 集成 OKX API，支持多时间周期K线数据查询和历史数据存储
- **📊 K线图表展示**: 可视化K线数据，支持5分钟、15分钟、1小时、4小时、1天等多个时间周期

## 功能详解

### 1. 实时价格监控

每10分钟采集一次数据，显示：
- 当前价格（美元）
- 10分钟涨跌幅
- 24小时涨跌幅
- 24小时涨跌幅排名

**颜色标识**:
- 🟢 绿色：上涨
- 🔴 红色：下跌

### 2. 涨跌分析

**涨跌统计**:
- 绿色占比：上涨币种数量 / 总币种数量
- 红色占比：下跌币种数量 / 总币种数量

**急涨急跌**（每轮统计）:
- 急涨：单轮涨幅 ≥ 1%
- 急跌：单轮跌幅 ≤ -1%
- 累计今日急涨/急跌总次数

**极端行情**（每轮统计）:
- 极涨：单轮涨幅 ≥ 4%
- 极跌：单轮跌幅 ≤ -3%

### 3. 市场趋势分析

系统根据以下规则判断市场趋势：

**五种市场状态**:

1. **单边主升** ⭐⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 3
   - 特征：强烈上涨趋势

2. **震荡偏多** ⭐⭐
   - 条件：急涨 ≥ 10 且 创新高 - 创新低 ≥ 1
   - 特征：上涨趋势，但有波动

3. **无序震荡**
   - 条件：急涨 < 10 且 急跌 < 10
   - 特征：市场方向不明确

4. **震荡偏空** ☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 1
   - 特征：下跌趋势，但有反弹

5. **单边主跌** ☆☆☆
   - 条件：急跌 ≥ 10 且 创新低 - 创新高 ≥ 3
   - 特征：强烈下跌趋势

**趋势强度星级**:
- 比值 = |急涨 - 急跌| / min(急涨, 急跌)
- 1-2：⭐ 一颗星
- 2-3：⭐⭐ 两颗星
- ≥3：⭐⭐⭐ 三颗星

**星星类型**:
- ⭐ 实心黑星：急涨
- ☆ 空心黑星：急跌

### 4. 创新高/创新低

**比价系统**:
- 系统储存每个币种的历史最高价和最低价
- 每轮结束后，将当前价格与历史极值比较
- 如果价格 > 历史最高价 → 创新高，更新记录并计次
- 如果价格 < 历史最低价 → 创新低，更新记录并计次

**占比计算**:
- 最高占比 = (当前价格 / 历史最高价) × 100%
- 最低占比 = (当前价格 / 历史最低价) × 100%

### 5. 币种优先级等级

根据最高占比和最低占比自动分配等级：

| 等级 | 条件 | 说明 |
|------|------|------|
| 🥇 等级1 | 最低占比 ≥ 120% 且 最高占比 ≥ 90% | 价格接近历史高位且远离低位 |
| 🥈 等级2 | 最低占比 ≥ 120% 且 最高占比 ≥ 80% | 价格较高且远离低位 |
| 🥉 等级3 | 最低占比 ≥ 110% 且 最高占比 ≥ 90% | 价格接近历史高位 |
| 4️⃣ 等级4 | 最低占比 ≥ 110% 且 最高占比 ≥ 80% | 价格较高 |
| 5️⃣ 等级5 | 最低占比 < 110% 且 最高占比 ≥ 90% | 价格接近历史高位但靠近低位 |
| 6️⃣ 等级6 | 其他情况 | 价格处于中低位 |

### 6. 风险提示

当绿色占比 = 0%（所有币种全部下跌）时，系统会：
- 风险计次 +1
- 显示 "⚠️ 注意风险" 警告

### 7. 🆕 K线数据查询

**数据来源**: OKX 交易所 API

**支持的时间周期**:
- 5分钟 (5m)
- 15分钟 (15m)
- 1小时 (1H)
- 4小时 (4H)
- 1天 (1D)

**功能特性**:
- ✅ 实时同步 K线数据（最多300根K线）
- ✅ 历史数据存储和查询
- ✅ K线统计信息（涨跌幅、最高最低价、成交量）
- ✅ 可视化图表展示
- ✅ 多时间周期对比
- ✅ 单个币种详细查询

**OKX 配置参数**:
- V1: 第一阈值参数
- V2: 第二阈值参数

每个币种都有独立的 OKX 交易对配置（如 BTC-USDT-SWAP）

## 技术架构

- **框架**: Hono (轻量级 Web 框架)
- **运行时**: Cloudflare Workers / Pages
- **数据库**: Cloudflare D1 (SQLite)
- **前端**: HTML + TailwindCSS + Vanilla JavaScript + Chart.js
- **数据源**: CoinGecko API (现货价格) + OKX API (K线数据)
- **部署**: Cloudflare Pages

## 数据库结构

### 核心表

1. **coins** - 币种配置
2. **price_records** - 价格记录（每10分钟）
3. **price_extremes** - 历史最高/最低价
4. **round_stats** - 轮次统计
5. **coin_round_details** - 单币轮次详情
6. **daily_stats** - 日统计
7. **extreme_records** - 创新高/新低记录
8. **coin_priority** - 币种优先级
9. **🆕 kline_data** - K线历史数据
10. **🆕 okx_config** - OKX 币种配置（V1/V2参数）

## API 端点

### 现货价格监控 API

#### GET /api/dashboard
获取仪表板数据（最新轮次、币种详情、今日统计、极值数据、优先级）

#### POST /api/analyze
执行一轮数据采集和分析

#### GET /api/coins
获取所有币种列表

#### GET /api/rounds?limit=50
获取历史轮次统计

### 🆕 K线数据 API

#### POST /api/kline/sync?timeframe=5m&limit=300
同步所有币种的 K线数据
- `timeframe`: 时间周期（5m/15m/1H/4H/1D）
- `limit`: 获取的K线数量（默认300）

#### GET /api/kline/:symbol?timeframe=5m&limit=100
获取单个币种的 K线数据
- `symbol`: 币种符号（如 BTC）
- `timeframe`: 时间周期
- `limit`: 返回的K线数量

#### GET /api/kline/:symbol/stats?timeframe=5m&limit=100
获取 K线统计信息（涨跌幅、最高最低价、成交量等）

#### GET /api/kline/:symbol/multi
获取单个币种的多时间周期数据（5m/15m/1H/4H/1D）

#### GET /api/okx/config
获取所有币种的 OKX 配置

#### GET /api/okx/config/:symbol
获取单个币种的 OKX 配置

## 使用说明

### 主页 - 实时监控

1. **首次使用**: 点击 "执行分析" 按钮进行第一次数据采集
2. **自动更新**: 系统会每10分钟自动执行一次分析
3. **查看数据**: 在仪表板查看实时价格、涨跌统计、市场趋势
4. **手动刷新**: 可随时点击 "执行分析" 按钮手动触发更新

### 🆕 K线查询页面

1. **访问**: 点击首页的 "K线查询" 按钮或访问 `/kline.html`
2. **同步数据**: 首次使用点击 "同步数据" 按钮从 OKX 获取 K线数据
3. **选择币种**: 点击币种按钮查看对应的 K线数据
4. **切换周期**: 选择不同的时间周期（5m/15m/1H/4H/1D）
5. **查看图表**: 系统自动生成 K线图表和统计信息
6. **查看表格**: 下方显示详细的 K线数据表格

**注意**: K线数据需要手动同步，系统不会自动更新。建议每天同步一次以获取最新数据。

## 数据说明

### 数据来源
- **现货价格数据**: CoinGecko Free API
  - 更新频率：每10分钟（自动）
  - 计价单位：美元 (USD)
  
- **🆕 K线数据**: OKX Exchange API
  - 更新方式：手动同步
  - 时间周期：5m/15m/1H/4H/1D
  - 数据量：最多300根K线

### 数据限制
- CoinGecko 免费版 API 有请求频率限制
- OKX API 免费且无需注册
- 建议不要过于频繁地手动触发数据同步
- K线数据会存储在本地数据库中，可离线查询历史数据
