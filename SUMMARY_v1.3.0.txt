│ ✨ 核心功能列表                                                         │
└─────────────────────────────────────────────────────────────────────────┘
  
  1. 📊 当天统计面板（4项指标）
     ├─ 起涨触发次数: 20根K线累计涨幅 > +2%
     ├─ 起跌触发次数: 20根K线累计跌幅 < -2%（测试阈值，原本-3%）
     ├─ 最长连续上涨: 占比上涨>占比下跌的最长连续数（含结束时间）
     └─ 最长连续下跌: 占比下跌>占比上涨的最长连续数（含结束时间）
     
     特点:
     • 绿色背景 = 上涨指标
     • 红色背景 = 下跌指标
     • 自动重置（每天0:00）
     • 最低数据要求: 20根K线
     
  2. ⏰ 时间逻辑优化
     ├─ 问题: 午夜后0:11-0:12的记录被错误计入"今天"
     ├─ 解决: 添加1小时缓冲区
     ├─ "今天"从北京时间1:00开始（不是0:00）
     └─ 影响范围: 创新高低统计、时间范围统计
     
  3. 📊 18个币种数据导入
     币种列表:
     ETH(0,1)   XRP(0,1)   SOL(1,3)   BNB(0,0)   DOGE(0,2)  ADA(0,5)
     TRX(0,0)   AVAX(0,4)  SHIB(0,0)  TON(0,1)   LINK(1,6)  BCH(1,0)
     NEAR(1,3)  SUI(0,5)   LTC(0,0)   UNI(1,2)   CRO(0,4)   TAO(2,3)
     格式: 币种(飙涨次数, 暴跌次数)
     
  4. ✅ 统计一致性修复
     ├─ 问题: 首页右上角和多指标面板显示的创新高低数量不一致
     ├─ 原因: daily_stats表中有昨天16:11-12的旧记录
     ├─ 解决: 清空今天的new_high_count和new_low_count字段
     └─ 结果: 两个面板均显示0（一致）
     
  5. 🐛 调试增强
     控制台日志输出:
     • 目标日期和数据条数
     • 统计结果详情
     • 累计涨跌幅最小值/最大值
     • 起涨点/起跌点数量
     • 累计跌幅最大的5个时间点

       cumulative = sum(change[i-20...i-1])
    
    2. 最长连续期追踪:
       if (upRatio > downRatio) {
         currentRisingStreak++;
         currentFallingStreak = 0;
       }

       beijingOffset = 8 * 60 * 60 * 1000

  1. 起跌触发次数经常为0
     原因: 市场波动小，20根累计跌幅未达-2%
     解决: 正常现象，不是bug
     验证: 查看控制台"最小值"是否 > -2%
  
  2. 统计面板不显示
     原因: 当天数据不足20根（例如凌晨1-2点）
     解决: 等待数据积累或查看其他币种
  
  3. 时间显示为"-"
     原因: 最长连续期为0（没有满足条件的数据）
     解决: 正常现象，等待市场波动
  
  4. 起跌阈值-2%是测试值
     原因: 原本-3%太严格，临时降低到-2%用于测试
     恢复: 参考DEBUG_GUIDE.md修改回-3%
